Ruianese 基於 Rime 的瑞安話拼音輸入法A Rime keyboard for the Rui'an dialect

按瑞安話讀音打字：打 ssang 出「人」，打 va 出「話」。字音以張永愷《瑞安方言讀音字典》為主，並補充陳海芳田野調查、《瑞安方言曲藝韻書》與溫州話常用詞。免費、開源，macOS、Windows、Linux 皆可用。 Type by Rui'an pronunciation: ssang gives 人, va gives 話. Readings come mainly from Zhang Yongkai's Rui'an pronunciation dictionary, supplemented by Chen Haifang's field survey, a Rui'an rhyme book and common Wenzhounese words. Free and open source for macOS, Windows and Linux.

拼音方案Spelling scheme

一個字母對一個音One spelling for each sound

瑞安話保留清、送氣、濁三分，所以濁音用雙字母表示：b 補、p 鋪、bb 步。拼寫以 IPA 為依據，輸入時一律用普通鍵盤字母。 Rui'an keeps a three-way contrast of plain, aspirated and voiced consonants, so voiced sounds use doubled letters: b, p, bb. Every spelling is based on IPA, and everything is typed with ordinary letters.

聲調Tones8

聲調可以不打：打 ssang 就會出「人」。想精確選字時，選「瑞安話（帶調）」方案，在拼音後加 1–8，例如 ssang5。張永愷字典區分的尖團音（如 zie / jie）兩種拼法都能打。 Tones are optional: ssang already gives 人. For exact matches, switch to the 瑞安話（帶調） layout and add 1–8, e.g. ssang5. Where Zhang's dictionary distinguishes sibilant pairs such as zie / jie, both spellings work.

安裝Install

四步裝好Four steps to install

輸入法跑在免費的 Rime 中州韻 引擎上。先裝 Rime，再放入瑞安話方案。The keyboard runs on Rime, a free input-method engine. Install Rime first, then add the Ruianese layout.

  1. 安裝 RimeInstall Rime

    下載並安裝 鼠鬚管 Squirrel。然後到 系統設定 → 鍵盤 → 文字輸入 → 編輯… → ＋，選「簡體中文」或「繁體中文」裡的 Squirrel，按「加入」。沒看到 Squirrel 的話，先登出再登入一次。Download and install Squirrel. Then open System Settings → Keyboard → Text Input → Edit… → +, choose Squirrel under Chinese, Simplified or Traditional, and click Add. If Squirrel is not listed, log out and back in first.

    下載並安裝 小狼毫 Weasel。Download and install Weasel.

    用套件管理器安裝 fcitx5-rime（Fcitx5）或 ibus-rime（IBus），以及 rime-data。Install fcitx5-rime (Fcitx5) or ibus-rime (IBus) and rime-data with your package manager.

  2. 下載瑞安話方案Download the Ruianese layout

    ruianese-rime.zip

    解壓後，把全部檔案複製到 Rime 用戶資料夾：Unzip it and copy every file into your Rime user folder:

    ~/Library/Rime
    %APPDATA%\Rime

    也可以從開始選單打開：小狼毫輸入法 → 【小狼毫】用戶文件夾。Or open it from the Start menu: 小狼毫輸入法 → 【小狼毫】用戶文件夾.

    ~/.local/share/fcitx5/rime   # Fcitx5
~/.config/ibus/rime          # IBus
  3. 啟用方案Turn the layout on

    在同一個資料夾打開（或新建）default.custom.yaml，寫入：In the same folder, open (or create) default.custom.yaml and add:

    patch:
  schema_list:
    - schema: ruianese
    - schema: ruianese_tone
    - schema: luna_pinyin

    這個清單會取代 Rime 預設的方案清單，若有其他常用方案請一併列上。This list replaces Rime's default one, so keep any other layouts you use.

  4. 重新部署，開始打字Deploy and type

    點選單列的 Squirrel 圖示 → 重新部署。Click the Squirrel icon in the menu bar → Deploy.

    開始選單 → 小狼毫輸入法 → 【小狼毫】重新部署。Start menu → 小狼毫輸入法 → 【小狼毫】重新部署.

    Fcitx5：右鍵托盤圖示 → 重新部署；IBus：Rime 選單 → 重新部署，或執行 ibus restart。Fcitx5: right-click the tray icon → Deploy. IBus: Rime menu → Deploy, or run ibus restart.

    第一次部署要建字典，約需一分鐘。之後切換到 Rime 就能打瑞安話；按 Ctrl+` 可切換「瑞安話」與「瑞安話（帶調）」，按 Shift 切換中英文。The first deploy builds the dictionary and takes about a minute. Then switch to Rime and type. Press Ctrl+` to switch between 瑞安話 and 瑞安話（帶調）, and Shift to toggle English.

打不出字？多半是改了檔案後還沒重新部署。macOS 上看不到圖示，則是還沒把 Squirrel 加入輸入法（第 1 步）。No candidates? You probably changed files without deploying again. No icon on macOS? Squirrel has not been added as an input source yet (step 1).
